# Coupled Meta-Learning Adaptive Filtering for Active Noise Control Under Time-Varying Acoustic Paths

This repository is the official project page for the paper: **“Coupled Meta-Learning Adaptive Filtering for Active Noise Control Under Time-Varying Acoustic Paths”** The manuscript has been submitted to the journal **Signal Processing**.

## Code Availability

The source code and experimental implementation associated with this work will be made publicly available in this repository **upon acceptance of the paper**. Please stay tuned for updates.
